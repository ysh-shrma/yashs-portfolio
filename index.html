Under the hood

The constraints that make it work.

The output is good because the rules are enforced, not suggested. A few that run on every session:

// economics

Every feature anchored to dealer ROI

Straight from our CEO's framework: a car on the lot costs ~$50/day. If a feature doesn't cut days-in-inventory or protect gross margin, it doesn't ship. Claude knows this before I say a word.

// writing

An enforced writing system

Plain language, active voice, no filler. "3 days → 4 hours", never "significant improvement." I built a /humanize command that rewrites any doc to the style guide.

// evals

An LLM eval system on every call

Scores agent calls across 6 dimensions (information accuracy, tool usage, conversation quality, escalation, conversion) with Python to aggregate and compare against human notes.

// sync

Cross-system, never dropped

Every requirement pushes to Jira and Notion with a sync map tracking each task. Claude flags any spec drafted but not yet pushed to both before a session ends.
